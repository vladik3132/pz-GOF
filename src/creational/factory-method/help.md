Фабричний метод — це коли ти створюєш спеціальну "майстерню" (клас-фабрику), яка бере на себе всю брудну роботу по створенню об'єктів.



"Фабрика потрібна для того, щоб заховати складність створення об'єктів. Мій головний файл (index.ts) просто просить 'річ', а Фабрика знає, який саме клас для цього створити. Це робить код гнучким: ми можемо додавати нові типи повідомлень, не переписуючи логіку всієї програми."
